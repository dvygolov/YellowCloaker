# Scripts

## Для чего нужен раздел Scripts

Этот раздел управляет дополнительным поведением страниц и переходов.

## Основные опции

- **Backfix** — при попытке вернуться назад открывает один из заданных резервных адресов.
- **Next Step Redirect** — после открытия следующего шага в новой вкладке перенаправляет текущую вкладку.
- **Form Submit Redirect** — перенаправляет текущую вкладку после отправки формы на завершающем шаге.
- **Page Loading** — включает ленивую загрузку изображений.

Все бинарные параметры управляются одинаковыми переключателями **Off/On**. Зависимые поля показываются только во включённом состоянии. При сохранении каждый параметр по-прежнему записывается одним булевым значением.

![Раздел scripts](../assets/screenshots/scripts-settings-overview.png)

Отслеживание конверсий настраивается отдельно в разделе **Conversions**. Успешная проксированная форма на последнем шаге может создать выбранный zero-payout статус, а опциональный Website status tracking инжектирует функцию `ytdsConversion(status)`. Оба источника используют тот же каталог и историю, что входящий postback.

Пороги прокрутки и видимого времени, performance-метрики и пользовательские браузерные события настраиваются отдельно в разделе [Events](events.md).
