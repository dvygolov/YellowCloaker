# Кампании

## Что такое кампания

Кампания — это верхний уровень настройки. Внутри кампании хранятся:

- domains
- настройки Safe Page
- black settings
- scripts
- postbacks
- statistics

## Основные действия

Из dashboard можно:

- создать кампанию
- дублировать кампанию
- открыть статистику одним нажатием на название кампании
- открыть редактор через **Actions → Settings**
- удалить кампанию

Переименование перенесено в редактор кампании: нажмите значок карандаша справа от названия в верхней части бокового меню. Откроется обычный диалог ввода нового имени.

## Домены

Кампания определяется по домену. Домены указываются без `http://` или `https://`.

Поддерживаются wildcard-значения, например:

- `*.example.com`
