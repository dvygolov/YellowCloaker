# Обзор продукта

## Что такое YellowTDS

YellowTDS — это PHP-система распределения и маршрутизации трафика. Она определяет, какой сценарий нужно применить к запросу:

- Safe Page
- offer funnel
- trafficback

Система хранит данные о кликах, лидах, выплатах, событиях и настройках кампаний в SQLite и предоставляет админ-панель для управления.

## Основные сущности

- кампания
- домены кампании
- настройки Safe Page
- настройки flows
- flow
- step
- postback settings
- statistics settings

## Основные сценарии использования

- отправлять модерацию, ботов или нежелательный трафик на safe page
- отправлять целевой трафик в воронку с несколькими шагами
- анализировать кампании через grouped statistics
- принимать статусы и payout через postbacks

## Поддерживаемые режимы

- direct mode
- JS Connect
- PHP Connect
