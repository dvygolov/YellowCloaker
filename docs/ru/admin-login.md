# Вход в админку

## Где находится админка

Основная точка входа:

- `/admin/`

![Страница входа в админку](../assets/screenshots/admin-login-page.png)

Если открыть `/admin` без завершающего слэша, происходит редирект на корректный путь.

## Пароль

Пароль администратора задаётся в:

- `settings.php`

Ключ:

- `adminPassword`

## Ограничение по домену

Если нужно открыть админку только на одном домене, можно использовать:

- `adminDomain`

## Ограничение по IP

Если нужно пускать в админку только с определённых IP, можно использовать:

- `adminIp`

Значение содержит один или несколько IPv4/IPv6-адресов через запятую, например `198.51.100.10, 203.0.113.15, 2001:db8::10`. Доступ разрешается, если текущий IP совпадает с любым адресом списка. Старое значение с одним IP продолжает работать.

Если сайт стоит за Cloudflare, для проверки IP будет использован `CF-Connecting-IP`, но только если IP прокси-запроса действительно принадлежит Cloudflare. Для этой проверки нужна читаемая и свежая ASN-геобаза.

При выключенном **Debug Mode** несовпадение разрешённого домена или IP возвращает только обычный ответ `404 Not Found`. Разрешённое и фактическое значения в публичный ответ не попадают. При включённом **Debug Mode** вместо этого показывается диагностическая причина отказа.

## Авторизация и защита

Логин работает так:

- пароль отправляется в `admin/login.php`
- успешный вход записывает `$_SESSION['loggedin'] = true`
- неудачные попытки ограничиваются rate limiter

Если пароль в `settings.php` пустой, фактически защита отключается, поэтому на production это недопустимо.
